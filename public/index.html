How it works

Three steps. Very little ceremony.

01

Paste the URL

Add any public HTTP or HTTPS page. Give it a name if human memory deserves help.

02

We save a baseline

Visible text is extracted and hashed. Scripts and layout noise are discarded before comparison.

03

You get the diff

When the text changes, see added and removed lines in the dashboard and optionally send a webhook.
